# Warlord v1.5.12.6.2 — superseded by v1.5.12.7

These are the `HELP.TXT` and `UNITS.INI` files that shipped with the v1.5.12.6.2
hotfix. They are retained only as version-comparison evidence. The parent directory
contains the current v1.5.12.7 roster and helptext used to generate the calculator's
Warlord unit data.

Compared with v1.5.12.6.2, v1.5.12.7 rebalances Fire Giant and Doom Bat, renames the
Idol/Bless of the Heavenly Bull to Divine Bull, revises several spell descriptions,
and documents other release changes in the current manual.
