# D32 — modern Raise Dead identity locate

Package and method: [`D30_D31_D32`](../DOS%20reconstructed/D30_D31_D32.evidence.md), Method 4.
The frozen binary is the exact CoM2 1.05.11 `Caster.exe` identified in [README.md](./README.md),
which is also Warlord 1.5.12.9's compiled engine. Calculator scope is `com2_1.05.11` and,
subject to the script-layer note below, `com2_warlord_1.5.12.9`. Calculator behavior is unchanged.

## Symbol, executable body, callers, and tail

TD32 assigns `@Spells@InitializeCombatSpellcasting` the symbol extent
`[0x5CC49C,0x5CD644)`. Linear decode and control flow bound executable code to
`[0x5CC49C,0x5CD586)`, 4,330 bytes and 1,099 instructions, SHA-256
`5fb6670cc07ce3108d78c37ec014472f9f40cfc7059359e6052843963456814f`. The only ordinary
return is the epilogue `8A 45 FB 8B E5 5D C3` at `[0x5CD57F,0x5CD586)`.

Twelve direct branches converge on that return: `0x5CCBF3`, `0x5CCCA1`, `0x5CCD4F`,
`0x5CCDFC`, `0x5CCE46`, `0x5CCE90`, `0x5CCEDA`, `0x5CCF24`, `0x5CD057`, `0x5CD060`,
`0x5CD55E`, and `0x5CD567`. The first ten are the pre-case straddlers reported by the bounded
Raise Dead scan; the last two lie after the case, reconciling the earlier 10-versus-12 count.

The symbol tail `[0x5CD586,0x5CD644)`, SHA-256
`1c9eac6e526b31fe24150d082120f50d425d7441ef793cc3b6bec51941f2b0f0`, is not padding. Nine
`mov edx, immediate` operands in earlier spell cases reference its Unicode node-name constants.
No branch or call enters the tail, and the next TD32 symbol begins at `0x5CD644`, so it is
routine-owned post-return data rather than executable code.

The sole in-image direct caller of the producer entry is `0x644368` in the complete wrapper
`@Castercore@InitializeCombatSpellcasting` `[0x64435C,0x644377)`, 27 bytes, SHA-256
`33665726dc8b3e4817e31d36e797cab7fb5878b8e7278da2a9e4e54d7337a54a`. Its direct caller is
`0x659F34` in `@Uispell@CastCombatSpell`. `CasApi.pas` declares the wrapper as the script-callable
combat-spell initialization API, closing the API frontier.

## Raise Dead case and producer

Both base and Warlord `MASTER.CAS` define `SRaiseDead = 137` (`$89`) and
`SAnimateDead = 195` (`$C3`). The exact Raise Dead gate/case is
`[0x5CD1FF,0x5CD372)`, 371 bytes, SHA-256
`1d1c4425bb0cad13420d98164cfc5052ba2da9b82832321e042b57870a7b55bf`:

```text
5CD1FF  81 7D FC 89 00 00 00    cmp dword ptr [ebp-4],$89
5CD206  0F 85 66 01 00 00       jne $5CD372
```

The case body `[0x5CD20C,0x5CD372)` falls through to the next spell test. The six nonlocal
compiler-guard exits are calls at `0x5CD21B`, `0x5CD229`, `0x5CD2D7`, `0x5CD2E5`, `0x5CD328`,
and `0x5CD340`. The target unit index enters through global `$0070802C`.

After `@Units@RemoveAllEnchantments` at `0x5CD245`, the relevant ordered state is:

| VA | Named write or call |
|---|---|
| `0x5CD24D` | `Irrecoverabledamage := 0` (`+$502`) |
| `0x5CD259` | `Undeaddamage := 0` (`+$504`) |
| `0x5CD265` | `CombatEnchantmentFlags[EncNoHeal] := 1` (`+$60E`) |
| `0x5CD26F`, `0x5CD279`, `0x5CD283` | `dead`, `undeaded`, `irrecoverable := 0` |
| `0x5CD28D`, `0x5CD297`, `0x5CD2A1` | `confusioneffect`, `webleft`, `Displayrace := 0` |
| `0x5CD2B2`, `0x5CD2C2` | restore combat coordinates |
| `0x5CD2FB` | `combatmovesleft := combatmaxmoves` |
| `0x5CD30C` | call `@Units@RecalculateUnits` |
| `0x5CD318` | call `@Units@HpPerFigure` |
| `0x5CD34D` | `Totaldamage := trunc(HpPerFigure * figures / 2)` (`+$500`) |
| `0x5CD361` | publish target unit ID through `$00709BDC` |
| `0x5CD36D` | call `@Units@RecalculateUnits` |

`CombatEnchantmentFlags` begins at `+$5D1`; one-based element 62 is
`0x5D1 + 61 = 0x60E`, proving the producer's raw displacement is `EncNoHeal`. Writing
`Totaldamage` equal to half maximum HP represents damage sustained and therefore revival at half
health; it is not a health-field assignment.

The existing checked reconstruction [Units.RecalculateUnits.pas](./Units.RecalculateUnits.pas)
consumes `EncNoHeal` in `[0x5A0420,0x5A04A9)`, writes `race := 21` and `Fantastic := True`, and
converges at `0x5A04A9`. D32 must cite that consumer rather than reconstruct it again. The sibling
Animate Dead case `$C3` is intentionally excluded.

## Warlord and fixed-extent successor

The compiled producer/consumer path is identical in CoM2 and Warlord because they use the same
executable. Behavioral conclusions for Warlord must nevertheless check its higher-precedence
`COSpell.CAS`: the Warlord script adds post-Raise Dead/Animate Dead live-unit recount logic that
the base script lacks.

[D36](./D36.evidence.md) completed the fixed successor in
[Spells.InitializeCombatSpellcasting.pas](./Spells.InitializeCombatSpellcasting.pas), reconstructing
only `[0x5CD1FF,0x5CD372)` and wrapper `[0x64435C,0x644377)`. Its two complete ledgers retain the
six guard sites, outbound calls and globals above, enclosing entry/return context, and excluded
`$C3` sibling. The existing recalculation consumer stays in its present owner.
