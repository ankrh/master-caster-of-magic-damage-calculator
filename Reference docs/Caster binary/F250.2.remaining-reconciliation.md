## The shipped raw table narrows the question

`Raw install files/CoM2ModWarlord1.5.12.9/CoMWin1511/Spells.dat` has 73,784 bytes, exactly
401 records of 184 bytes. SHA256:
`3adf520c42c7d903ab77451392662ff484731efcf876eb169eb7172cac79bf1d`.
Reading a length-prefixed name at record+0 and signed little-endian dwords at +0x2C/+0x90 gives:

| Slot | Raw name | +0x2C | +0x90 |
|---|---|---:|---:|
| 53 | Vertigo | 13 | 25 |
| 67 | Mind Storm | 14 | 14 |
| 88 | Shatter | 16 | 11 |
| 89 | Warp Creature | 5 | −1 |
| 131 | True Sight | 1 | 41 |
| 162 | Weakness | 13 | 13 |
| 165 | Black Sleep | 13 | 46 |
| 272, 338, 343 | empty | 0 | 0 |

These are named raw records matching the base configuration, stronger than numeric coincidence
between unrelated INI fields. They are **not a runtime memory capture**. The same file cannot
establish Warlord's configured Shatter/Rebuild/Conjuring Pact records or its changed Weakness
group: those differ from these bytes. The loader supplement identifies the cache/INI choice; actual selected files and runtime
contents remain conditional.

Reproduce without disassembling code:

```python
from pathlib import Path
import hashlib, struct
p = Path('Raw install files/CoM2ModWarlord1.5.12.9/CoMWin1511/Spells.dat')
b = p.read_bytes()
print(len(b), hashlib.sha256(b).hexdigest())
for slot in (53, 67, 88, 89, 131, 162, 165, 272, 338, 343):
    o = slot * 184
    print(slot, b[o+1:o+1+b[o]],
          struct.unpack_from('<i', b, o+0x2C)[0],
          struct.unpack_from('<i', b, o+0x90)[0])
```
