**Source notation and contracts.** The Pascal below reconstructs source structure, not original declarations. `PtrAt(G)` reads the current pointer from global slot `G`; `DWordAt`, `ByteAt`, and `ShortStringAt` describe memory access. Named table views are defined by the address formulas below and reload their pointer globals where the instructions do.

`ReadInteger` and `ReadString` denote calls through object VMT slots `+$0C` and `+$04`. Their source meanings, string expressions, `Free`, and exception syntax are conditional on the corresponding runtime contracts. No omitted helper is assumed to preserve registers or never return. The precise arithmetic/error-continuation qualifications below apply to all abbreviated indexed operations.

The `.dat` runtime call sequence supplies `$12038` to `ResetFile` and the current spell-table pointer to `ReadRec`. The identity `$12038 = 401 × $B8` is consistent with a file record containing spell slots `0..400`, but does not recover the typed-file declaration or prove the opaque read’s effects.

Normal completion jumps from `$6366AE` to `$6366C6`. The exception continuation calls the first loader before joining there, if its calls complete. There is no explicit `Close` in that continuation and no file-closing `finally` here. An exception from the fallback loader has no second recovery shown in this slice; propagation out of the **entire** initializer cannot be established without its enclosing code and runtime handlers. The entry and loop back have the ordinary shape `for i := 0 to n`, but the supplied fragments do not prove that the omitted body preserves the loop state or reaches both stores. In particular, each field fragment formats the then-current `i` **before** its virtual call and reloads `i` **after** that call. Matching the section number to the destination slot requires that call not to change the relevant local.

Both store tails compare the index **unsigned** against `$190`, multiply it by 23 using signed checked `IMUL`, and use address scale 8. This establishes the `$B8` stride and passing index range `0..400`. Both writes are full dwords, without a value clamp or byte conversion.

**INI helper derivation.** The supplied file bytes contain:

```text

DWord_file[$46BEC4 + $04] = $46CF28  { ReadString }
DWord_file[$46BEC4 + $0C] = $46C2D0  { ReadInteger }
```

Constructor calls supply `EAX=DWordAt($46BE6C)`, `DL=1`, and the filename in `ECX`. The constructor calls opaque `ClassCreate` at `$46C232` **before** copying its then-current `ECX`, `EDX`, and `EAX` into `ESI`, `EBX`, and `EDI`. It passes `EDI+4` and `ESI` to `UStrAsg`, conditionally calls `AfterConstruction`, and finally sets `EAX := EDI`. Machine-level qualification: `value` is held in `EBX` across cleanup, and `$46C390` copies **then-current** `EBX` to `EAX`. The result therefore depends on the omitted cleanup helpers preserving that register.

`StrToIntDef` saves the default in `EBX`, supplies a stack status address to opaque `ValLong`, and tests that status at `$421F57`. A zero status retains returned `EAX`; nonzero status executes `EAX := EBX`. Interpreting that as returning the original default requires `ValLong` to preserve `EBX`. The parser’s accepted grammar is absent.

The source represents every supplied second-loader phase in order. Its `Free` calls occur on the straight-line path; neither is in the supplied finally cleanup.

The `Total`/`Picks` key construction uses short-string concatenation limits `$19`, then `$1D`, before Unicode conversion and appending the numeric book suffix. `Starting` uses limit `$1C`. The supplied rarity strings fit those limits. Both threshold literals spell **`Treshold`** exactly.

The first loader initializes its index to **0**; the second loader’s AI-priority/count loop initializes it to **1**. Under ordinary loop-state preservation, that second loop neither loads an AI priority for record 0 nor counts record 0.

The count operation uses `+$20` as a checked `1..4` column and `+$34` as a checked `1..6` row, and skips a record when its `+$44` byte is nonzero. This packet does not bind those fields to the names “rarity,” “realm,” or “unobtainable.” It directly zeros **only rows 1..5**, although the later increment admits **row 6**. Row 6’s prior state is unknown.

**Arithmetic and branch boundaries.**

- Fixed loops use wrapping increments and **not-equal** comparisons against the first excluded value. Their shown starts yield the Pascal ranges above if intervening calls leave the local loop state intact.
- The two second-loader data-driven loops capture the count once, skip it when signed `n <= 0`, initialize `i := 1`, and end each iteration with wrapping `INC i`, `DEC remaining`, then `JNE`. There is no count clamp.
- Lower-bound-one guards use wrapping `DEC`, unsigned comparison, and `INC`. Thus `Cardinal(Wrap32(x-1)) <= 3` admits `1..4`.
- Spell-record index checks admit `0..400`; the separate AI-priority destination check admits `1..400`.
- Default-pick source-name guards admit `1..6`, while destination guards admit `1..5`, `1..4`, `1..12`.
- Count row guards admit `1..6`, including in the five-row zeroing loop. Retort guards admit `1..18`; reroll destination guards admit `1..1000`, `1..3`.
- Every supplied `IMUL` is followed by a signed-overflow test. Effective-address scaling and `LEA` do not gain additional overflow checks. The count increment writes the wrapped dword **before** testing signed overflow.

Failed bounds call `$406EE0`; signed-overflow paths call `$406EE8`. If those calls return, execution falls through with their resulting register and memory state. For example, the exact first-field store tail is:

```pascal
EDX := DWordAt(EBP-4);
if Cardinal(EDX) > $190 then Call406EE0;
EDX := SignedIMUL32(EDX, 23, OF);
if OF then Call406EE8;
ECX := DWordAt($708164);
DWordAt(Wrap32(ECX + EDX*8 + $2C)) := EAX;
```

There is no save/restore of the returned field value in `EAX` or the index in `EDX` across those error calls. The high-level indexed assignments describe passing guards, or returning callees that independently satisfy the needed state contract.
