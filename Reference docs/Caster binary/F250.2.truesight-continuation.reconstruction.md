## Notation and exact evaluation rules

The following is source-shaped Pascal with explicit machine-state expansions where necessary. It does not claim to recover original declarations or complete helper signatures.

- `D`, `B`, `SW`, and `SB` access dwords, bytes, signed words, and signed bytes.
- `Indirect(A) = D[D[A]]`.
- Local names are memory aliases at the current `EBP`, not cached values.
- `CallAt(Address)` executes an opaque machine call. If it returns, its actual returned registers, memory, and stack remain in effect.
- All address arithmetic wraps to 32 bits unless an explicit checked operation is shown.
- Comparisons are signed unless marked unsigned; equality is sign-neutral.
- `Push32`, `Pop32`, and `MachineRET` describe actual stack operations, without assuming a callee cleanup convention.

These inline expansions preserve every supplied bounds/overflow call:

```pascal

begin
  if UInt32(R) > Maximum then
    CallAt($00406EE0);                  { BoundErr }
end;

procedure Bound1(var R: Register32; Maximum: UInt32);
begin
  R := Wrap32(R - 1);                   { DEC, no overflow call }
  if UInt32(R) > Maximum - 1 then
    CallAt($00406EE0);
  R := Wrap32(R + 1);                   { INC of actual returned register }
end;

procedure CheckedMul(var R: Register32; Factor: Int32);
begin
  R := Low32SignedProduct(R, Factor);
  if SignedMultiplyOverflow then
    CallAt($00406EE8);                  { IntOver }
end;

procedure CheckedAdd(var Destination; Amount: Int32);
begin
  Destination := Wrap32(Destination + Amount);
  if SignedAdditionOverflow then
    CallAt($00406EE8);
end;

procedure CheckedSub(var Destination; Amount: Int32);
begin
  Destination := Wrap32(Destination - Amount);
```
