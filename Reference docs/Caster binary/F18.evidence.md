# F18 — `@Units@applynodeaura` reconstruction evidence

## Scope and result

F18 reconstructs the complete natural TD32 routine `$0059718C..$005973A3` (535 bytes) in the
CoM2 1.05.11 engine. Warlord 1.5.12.7 bundles the same engine binary; the executable identities
and paths remain owned by [`README.md`](./README.md). The F18 slice in both copies has SHA-256
`46394c3045803f220dfc1d86b55adae6e63d250cc04a2ac93c1d2d91453d8b94`, and the Warlord
`UnitCalc.CAS`/`UnitCalcPre.CAS` files contain no scripted node-stat override. Calculator versions
in scope are `com2_1.05.11` and `com2_warlord_1.5.12.7`.

Before F18, the caller established when the helper runs but the helper body itself was missing.
F18 adds the complete source-shaped procedure to
[`Units.RecalculateUnits.pas`](./Units.RecalculateUnits.pas), corrects the calculator's modern
node-aura channel and gate model, and closes `PROVENANCE[nodeAura]`.

Method 4 was used: two independent Codex GPT-5.6 Sol High derivations covered the full extent,
the merged result passed the mechanical checker, and one Claude Opus 5 Medium review independently
decoded the bytes and accepted the reconstruction. The review found no byte-level semantic error.
It did expose two calculator mismatches—the melee gate's data layer and an unsupported Thrown
write—which are corrected in the same F18 package.

## Reconstructed behavior

`applynodeaura(i)` takes only the one-based unit index. Admission by node realm happens in its
three callers, not inside the helper. Once called, it executes these writes in order:

1. If persistent `BaseUnits[i].attack > 0`, add 2 to current `Units[i].attack` and its signed
   display bonus.
2. If current `Units[i].ranged > 0`, add 2 to that conventional Ranged field and its signed
   display bonus.
3. If current Fire Breath is positive, add 2 to Fire Breath.
4. If current Lightning Breath is positive, add 2 to Lightning Breath.
5. Add 2 to current Defense and its signed display bonus unconditionally.
6. Add 2 to current Resistance and its signed display bonus unconditionally.

The complete contiguous decode contains no Thrown, Gaze, To-Hit, To-Defend, or other gameplay
field operand. In particular, modern Thrown at `+$02C` is not part of the helper.

The melee asymmetry is material. A positive persistent Attack still receives the aura after an
earlier calculated penalty reduces its live subtotal to zero or below. Conversely, a live melee
field created only in the calculated record does not receive the aura when persistent Attack is
zero. Conventional Ranged and both Breath gates do read their current calculated fields.

The calculator projects the engine's independent conventional Ranged `+$024`, Fire Breath
`+$030`, and Lightning Breath `+$034` fields through separate modern child passes sharing its
`rtb` accumulator. F18 admits exactly those three child passes and rejects the independent Thrown
pass. Focused checks cover both the excluded Thrown channel and both directions of the
persistent-versus-live melee distinction.

## Frame, fields, and arithmetic

TD32 names the argument spill `[EBP-$04]` as `i` and the cached current-unit pointer at
`[EBP-$08]` as `$161453776`. Every lookup accepts indices 1..40,000 and uses the checked
`$01E1`-dword / `$0784`-byte record stride. The runtime data-block pointer is read from
`$00709188`; current `Units` element zero is at `$06426898`, while persistent `BaseUnits`
element zero is at `$01AC1798`.

| Layer | Field | Offset | Evidence |
|---|---|---:|---|
| base | Attack | `+$020` | signed gate read `$005971E7`, displacement `$01AC17B8` |
| current | Attack | `+$020` | dword write `$005971F4` |
| current | conventional Ranged | `+$024` | gate `$00597257`, dword write `$00597264` |
| current | Fire Breath | `+$030` | gate `$005972C7`, dword write `$005972D4` |
| current | Lightning Breath | `+$034` | gate `$00597303`, dword write `$00597310` |
| current | Defense / Resistance | `+$064 / +$068` | dword writes `$0059731E / $00597360` |
| current | Attack / Defense / Resistance / Ranged bonus | `+$6BC / +$6BE / +$6C0 / +$6C2` | word stores `$0059722C / $00597356 / $00597398 / $0059729C` |

Five unit lookups use the full checked idiom `DEC; CMP $9C3F; JBE; BoundErr; INC; IMUL $1E1;
JNO; IntOver`. Six Integer increments use checked `ADD [field],2`. Each of the four SmallInt
increments uses the complete Delphi range-check idiom: sign extension, checked `+2`, `+$8000`,
unsigned comparison with `$FFFF`, `BoundErr` on failure, `+$FFFF8000` correction, then word store.

`$0059729C`, `$005972D4`, `$00597310`, `$0059731E`, `$00597356`, `$00597360`, and `$00597398`.
Every destination dereferences the cached current `Units[i]` pointer.
