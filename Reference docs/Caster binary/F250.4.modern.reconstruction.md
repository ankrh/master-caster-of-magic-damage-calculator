## Notation

`D[a]` and `B[a]` access little-endian dwords and bytes. `L[n]` abbreviates `D[EBP-n]`, evaluated against the **current** EBP each time. Address arithmetic wraps at 32 bits.

`FS_D[a]` accesses a dword at segment FS offset a. `Push(x)` evaluates x, decrements
ESP by four and writes that dword; `Pop(r)` reads at ESP then increments ESP by four.
`Ret(n)` pops EIP and adds n to ESP. These operations preserve flags.

The following are compact architectural semantic primitives, not an emulator implementation:

- Assignments, address calculations, loads, stores, `Push`, `Pop`, and `Ret` preserve flags. An `AL` assignment replaces only EAX’s low byte; its source address is evaluated before replacement.
- Uppercase arithmetic/logical operations have their x86 operand-width results and flag effects. Operands are 32-bit except explicit `AL` operations. `INC`/`DEC` preserve CF; two-operand `IMUL` defines CF/OF and leaves other arithmetic flags undefined.
- `CMP` and `TEST` set flags without storing a result. `EQ/NE`, `S/NS`, `SLT/SLE/SGT`, `UB/UBE/UA/UAE`, and `NO` denote x86 conditions, not new comparisons.
- `SAR(x,1)` followed, only for a negative result, by `ADC(x,0)` implements signed halving toward zero, using the shift’s CF.
- `CDQ` sign-extends EAX into EDX without changing flags. `IDIV(d)` performs signed EDX:EAX division, returns quotient/remainder in EAX/EDX, leaves arithmetic flags undefined, and retains architectural division faults.
- Memory `BT(base,index)` tests the indexed bit across successive dwords, sets CF, preserves ZF, and leaves its other arithmetic flags undefined.
- `Push(x)` and `Pop(r)` perform real stack writes/reads. `Ret(n)` pops the return address and discards another `n` bytes.
- `Call(address)` includes the architectural return-address push. Supplied bodies execute as written below. Excluded callees have **unresolved register, flag, memory, and stack effects**. Subsequent statements apply only if control returns to that continuation, using the actual returned state.
- `Outside_$...` denotes an excluded continuation, entered with the current state. Labels within each procedure are local.
