The source adopts the revised GPT listing's explicit checked-address macros and call setup, checked against the revised Claude listing and binary. Both agree on the branch sets, byte stores, Warp mapping and common-tail ordering. Macro definitions are reconstruction notation, **not compilable original Pascal**. Unknown fields retain offsets; named external calls remain opaque. `Unsupplied_5CA369` is an external control-flow boundary, never an empty statement or implied fall-through. The separate tail continues the original frame.

The source covers 968 executable instructions in the eight extents listed in the evidence. Compiler prologues/epilogues are annotated; padding/string data are retained in the raw packet. At each generic store, the combat getter's displacement is used; the base getter is a separate address.

{ Memory:
    M8[a]  = byte at a
    M16[a] = word at a
    M32[a] = 32-bit value at a
    S8[a]  = signed byte at a, sign-extended to Int32

  CheckedAdd32 / CheckedSub32 / CheckedMul32:
    signed 32-bit arithmetic; overflow takes the supplied
    CALL $406EE8 path (TD32: IntOver).

  WrapAdd32 / WrapSub32:
    32-bit arithmetic without an inserted overflow check.

  BoundErr_406EE0:
    supplied range-error call target (TD32: BoundErr).
    Its implementation is not supplied.

  Effective-address additions/scaling have no further overflow
  checks unless explicitly stated.

  "and then" / "or else":
    left-to-right short-circuit evaluation.

  Opaque calls:
    observed addresses and register setup, not reconstructed bodies.
}

function SpellAddress(sp: Int32): Address;
var
  n: Int32;
  b: Address;
begin
  if UInt32(sp) > $190 then
    BoundErr_406EE0;

  n := CheckedMul32(sp, $17);
  b := M32[$708164];                 { loaded after checks/multiply }
  Result := b + n*8;                 { effective stride $B8 }
end;

function UnitScaled(u: Int32): Int32;
begin
  { DEC; unsigned CMP $9C3F; JBE; INC }
  if UInt32(WrapSub32(u, 1)) > $9C3F then
    BoundErr_406EE0;

  Result := CheckedMul32(u, $1E1);
end;

function UnitAddress(u: Int32; displacement: UInt32): Address;

  n: Int32;
  b: Address;
begin

end;
