## Findings

`Update_Sees_Illusions` clears both side-wide result words, then scans every active battle unit.
An active unit with Illusions Immunity (`Attribs_1 & 0x0008`) sets the result word belonging to
its controller's attacker or defender side. Units with any non-active status are ignored, units
controlled by neither combat-side player set neither word, and the routine does not stop after a
word becomes true (`0x7BDA3..0x7BE36`). The routine has no return value, calls, or battle-unit
writes.

The `0348:003E` call in `BU_ApplyDamage` at `0x876B5` resolves to this routine. In that caller it
runs after terminal damage has reduced the unit to zero figures and assigned its terminal status,
refreshing the side-wide flags against the now-current active-unit set.

Verified: Codex Agent A 2026-08-07, independent; Codex Agent B 2026-08-07, independent; followed
by reciprocal review. No disagreement survived.
