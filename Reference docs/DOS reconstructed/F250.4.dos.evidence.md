# F250.4 — DOS player-target Illusion refusal

The F250.4 section of [combat.c](combat.c) reconstructs the missing target-screen predicate
and its supplied loop/return continuation, independently for MoM 1.31, CP 1.60 and CoM 6.08.
[Raw packet](F250.4.dos.raw.md), [flow diagram](F250.4.dos.flow.svg).
The previously known AI and spell-handler guards are not rederived.

## Named local predicate

For requested spell indices 53 (Vertigo) and 67 (Mind Storm), the supplied raw records have
class 13 / 14 respectively, realm 1, low mask 1 / 8, high mask zero in every DOS build.
When those bytes are present at the live table reads, both pass the target-screen class
filter and reach the existing-effect check. The new source then establishes:

| First local refusal reached | Address | Record read |
|---|---|---|
| The spell's effect bit is already present | `0x8620E` clears DI | battle carrier `Combat_Effects`, word +0x22 |
| Otherwise, Sorcery and Illusion Immunity | `0x86295` clears DI | battle calculated `Attribs_1`, word +0x18, mask 0x0008 |

Field/flag names join existing combat.c and [unitcalc.c](unitcalc.c) only after independent
derivations. The raw predicate itself reads through the battle table pointer at DS:0x922A,
stride 0x6E, with target index from SS:[BP-0x0C]. The realm byte comes from the spell table
pointer at DS:0x912C, stride 0x24. This is a target-screen predicate, distinct from the
MoM 1.31-only AI selection test and the already reconstructed class 14 effect-handler check.

The evidence establishes the **local refusal write and record choice**, not a complete
validator. Earlier target selection/frame setup and actual LBX loading remain outside this
splice. A local DI clear precedes opaque calls; those callees' preservation is not inferred.
The later tests use actual live DI and may repeat the earlier UI loop or return the live
target local. Thus this source is not an unconditional Boolean return implementation.

## General source and differences

The existing-effect test sign-extends the one battle word with CWD; it does not read an
adjacent high battle word. It intersects that low/sign word pair with the spell's low/high
mask, then ORs the results. For the supplied Vertigo/Mind Storm masks, the high mask is zero.
Stack pushes/pops remain actual memory operations; no cached values replace them.

| Region | MoM 1.31 | CP 1.60 | CoM1 |
|---|---|---|---|
| Class 13/16/14 probes | Three spell-pointer reloads | Reuses first pointer for class 16; special A7 route | Reuses for class 16/14; special A7/AF routes |
| Zero overlap to realm read | Reload spell pointer | Reload spell pointer | Special 49/A2 checks, then inherited ES:BX |
| UI argument at 0x86924 | 2 | 1 | 1 |
| Final preparation | Three AX assignments/pushes | Clear live DS:9282; immediate pushes | Same as CP |

The special-ID routes are ordered: A7/AF enter the Death-attribute test directly only after
their preceding class comparisons fail. They bypass its realm test. The CoM1 49/A2 checks
occur only after zero overlap. None matches requested 53/67. These differences remain in the
source; matching requested local outcomes do not establish identical functions.

After Sorcery refusal's calls, execution falls through to a fresh spell lookup and Death
realm/Death Immunity check. That is sequential live-state logic, not a mutually exclusive
cached realm switch. Already-set refusal instead skips both realm checks.

The supplied route is `0x862F6 → 0x8675C → 0x868C9`. There are two separate live DI tests.
The intervening call sequence includes explicit PUSH CS followed by a **near** call at
0x8691C. Its runtime return IP must be mapped from the continuation file address 0x8691F;
truncating that file address is wrong. The caller body-relative offset is 0x106F. No callee
return convention or preservation is inferred. The final epilogue pops DI/SI before SP=BP.

## Existing sources reused and recalculation boundary

[A32](A32.evidence.md) already owns the human Shatter target-kind check, AI class 13/16
selection and generic cast store. [Mind Storm / True Sight](F250.3.mind-truesight.evidence.md)
owns the class 14 local guard and cast writer. Existing Combat_Resistance_Check and
Combat_Effective_Resistance remain their canonical resistance bodies; their lack of an
Illusion term does not erase the target-screen test above. No arithmetic is rederived here.

This new code is before effect application and does not establish the refresh sequence
after a cast. Its presence therefore neither proves nor disproves full calculator-pass
equivalence. Any later modeled admission must read the appropriate battle record at that
point, using the separately evidenced invocation schedule. No numeric gate is changed here.

## Method B and checks

605 instructions in 12 disconnected extents: 200 / 200 / 205. The same frozen raw packet went
to independent Astra medium and user-authorized Sol high fallback sessions. Original sessions
performed reciprocal reviews; fresh revisions received only own initial, other review and
raw. Both successful revised answers were read before merging.

Immutable answers/logs: `.derivations/F250.4.dos.*`; orchestration/reviews/check reports:
`.reviews/F250.4-dos/`. The merge retains architectural primitives and complete supplied
source, with no emulator implementation. Raw input/extent hashes, per-build citation coverage,
links and rendered SVG are checked. These source/reference changes move no calculator number.
