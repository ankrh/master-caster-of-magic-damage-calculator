# CAS citation grammar

How this repo cites a location inside a shipped `.CAS` script. `tools/cas_citation_audit.js` is the
checker; it is the executable statement of everything below. This file is itself in scope, so every
example on it resolves — a broken example fails the audit.

A `.CAS` filename with no locator after it is a **mention**, not a citation ("the `UnitCalcPre.CAS`
script"). Mentions are legal everywhere and are not audited.

## Shipped script sets

`Reference docs/Script source/<set>/`. Two sets ship: `Warlord 1.5.12.9` and `CoM2 1.05.11 base`.
A citation with no path prefix means `Warlord 1.5.12.9`. To cite the other set, prefix the
filename with its directory path. A prefix is a claim about which set, so it must end in a shipped
set's directory name; anything else, including a set the tree no longer ships, does not resolve.

## Locators

    citation     := [ prefix ] FILE ".CAS" locator
    locator      := label-anchor | text-anchor | line-list | span
    label-anchor := "!" LABEL "!" [ offset ] { " " statement }
    text-anchor  := "~" statement [ offset ] { " " statement }
    line-list    := ":" range { "," range }
    range        := N [ "-" M ]
    offset       := ("+"|"-") N [ ".." ("+"|"-") N ]
    statement    := '"' text-without-a-double-quote '"'
    span         := "@span:" line-count ":" sha256-prefix-24

### Label anchor — preferred

`UnitCalcPre.CAS!NOSPIRITLINK!` cites the line defining the `!NOSPIRITLINK!` jump target. Labels
are load-bearing (a `GOTO` names them), unique within a file, and survive insertions around them.
The label must be defined exactly once in the file.

`!LABEL!+7` is the 7th line after the definition, `!LABEL!-3` the 3rd before it, `!LABEL!+7..+19`
the span between. Offsets must land inside the file.

**An offset must carry a statement assertion**, because the offset is the one part of an anchor
that an edit between the label and the target moves silently:
`UnitCalcPre.CAS!NOSPIRITLINK!-11 "SETSTAT(U,AFantastic,0,1)"`. The quoted text, after whitespace
collapse, must occur verbatim on the first cited line. A range may carry a second statement, which
binds its last line, and should: one assertion pins one end only. Copy the text from the script. A
statement cannot contain `"`, so cite a fragment that has none.

### Text anchor

`MASTER.CAS~"SCaravanLogistic=117"` cites the one line containing that text. The text must occur
exactly once in the file, after whitespace collapse. This is the form for the two cited scripts
that define no labels at all — `MASTER.CAS`, a constants file, and `SpellMysticSurge.CAS` — and
for a `: section comment :` used as a landmark: `MASTER.CAS~":Overland Tiles:"`. It takes the same
optional offset and trailing statement assertion as a label anchor.

### Line list — deprecated

`UnitCalc.CAS:1486-1492`, `UnitCalcPre.CAS:104,263`. No spaces inside the list, so a comma with a
space after it ends the citation and `UnitCalcPre.CAS:81, OLSpell.CAS:586` is two of them. A line
number is checkable only against the file's length, and every script is replaced wholesale on each
mod release, which is what F227 exists to undo. New line-list citations are not written; the audit
holds the existing count as a ceiling.

### Span — delegated

A span pins a 1–40 line reviewed excerpt by content digest:

    // PROVENANCE[rust]: VERIFIED versions=com2_warlord_1.5.12.9; sources=Reference docs/Script source/Warlord 1.5.12.9/UnitCalc.CAS@span:10:98745d26b4fbf74694b1a932

It is generated by `tools/rebind_provenance_anchors.js` and resolved by `tools/provenance_audit.js`,
which reads a span only out of a line matching `// PROVENANCE[id]: …` exactly. A `STAT-FORMULA[id]`
marker declares a formula id and carries no sources, so it does not qualify.
`cas_citation_audit.js` therefore does not re-resolve a span; it checks only that no span sits
outside such a comment, where nothing would check it.

## Rules

- **A citation names its file.** A bare `:N` continuation ("…at `OverlandEndTurn.CAS:446`, upstream
  of the grants at `:523-545`") inherits its file from the nearest preceding citation in the same
  paragraph. The audit counts these but cannot gate on them: a bare `:N` is indistinguishable from
  a continuation of a `stats.js` citation. An anchor has no line number for a continuation to
  continue, so converting a citation means expanding any continuation hanging off it.
- **One citation, one file.** Cite two files as two citations.
- **No comma lists in an anchor.** Two labels are two citations.
